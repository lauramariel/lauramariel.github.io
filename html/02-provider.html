Provider Creation Flow

What gets created on Kubernetes when you create a "Provider" in NAI (e.g., "shared-nai" pointing to nai.example.com)

Key Takeaways

  • A Provider in NAI creates an AIGatewayProvider CR, a Secret (API key), and triggers creation of Envoy Backend + AIServiceBackend resources
  • The NAI IEP operator reconciles the AIGatewayProvider and creates the child Envoy resources
  • The Backend points to the external LLM provider hostname (e.g., nai.example.com)
  • AIServiceBackends define the API format (OpenAI-compatible, Cohere) and credentials
  • The provider hostname and API key are the only user inputs — everything else is auto-generated
