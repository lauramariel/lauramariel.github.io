Unified Endpoint Creation Flow

What gets created on Kubernetes when you create a "Unified Endpoint" in NAI (e.g., "uep-chat" that load-balances across models)

Key Takeaways

  • A Unified Endpoint creates an AIGatewayRoute CR that references the Gateway and provider backends
  • The route uses model-based routing — the x-ai-eg-model header determines which model handles the request
  • Load balancing is configured via weights (e.g., 50/50 split between gemma and gpt-oss)
  • Token tracking (input/output/total) is built into the route for usage monitoring
  • Envoy Gateway reconciles the AIGatewayRoute into an HTTPRoute on the Gateway
  • The endpoint is accessible at https://<gateway-ip>/enterpriseai/gateway/...
