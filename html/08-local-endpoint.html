Local Endpoint Serving Flow

What gets created on Kubernetes when you create a "Local Endpoint" in NAI (e.g., "llama-32-1b" served via vLLM on KServe)

Key Takeaways

  • A Local Endpoint creates a KServe InferenceService that manages Deployment + Service + HPA
  • The pod runs vLLM serving the model from the PVC (mounted at /mnt/models)
  • vLLM exposes an OpenAI-compatible API on port 8000 (chat completions, etc.)
  • Requires Intel AMX CPU (nodeSelector: cpu-cpuid.AMXBF16) for optimized inference
  • Tool calling is enabled (--enable-auto-tool-choice, --tool-call-parser=llama3_json)
  • The endpoint is accessible internally at http://llama-32-1b-predictor.nai-admin.svc.cluster.local
  • KServe handles the full lifecycle: deployment, service discovery, autoscaling, and health checks
