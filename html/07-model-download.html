Model Download Flow

What gets created on Kubernetes when you download a model in NAI (e.g., "llama-32-1b" from HuggingFace)

Key Takeaways

  • A Model creates a Model CR (iep.nai.nutanix.com/v1alpha1) and a PVC for storage
  • The Model CR tracks download progress: Pending → Processing → Active
  • Models are downloaded from HuggingFace (or NVIDIA NGC) using a stored API token (Secret)
  • The output is stored in a PVC at pvc://<name>-pvc-claim/model-files
  • The PVC uses the nai-nfs-storage StorageClass (NFS-backed)
  • Model size is specified at creation time (e.g., 10G) and determines PVC capacity
  • Once Active, the model can be used to create a Local Endpoint
