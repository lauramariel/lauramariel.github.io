MCP Connector Creation Flow

What gets created on Kubernetes when you create an "MCP Connector" in NAI (e.g., "weather-forecast" that exposes only the forecast tool from the weather MCP server)

Key Takeaways

  • An MCP Connector creates a new MCPRoute that filters tools from an existing MCP server
  • The toolSelector.include field specifies which tools are exposed (e.g., only nws_get_forecast)
  • A MCP Proxy Backend is auto-created, pointing to the extproc sidecar (192.0.2.42:9856)
  • The extproc sidecar handles tool filtering and MCP protocol translation
  • No new pods are created — the connector reuses the existing MCP server backend
  • The connector gets its own path: /enterpriseai/gateway/mcp/<connector-name>
  • Multiple connectors can filter different tool subsets from the same MCP server
