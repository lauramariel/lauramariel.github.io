MCP Server (Local) Creation Flow

What gets created on Kubernetes when you create a "Local MCP Server" in NAI (e.g., "demo-crm" running a container image)

Key Takeaways

  • A Local MCP Server deploys a container (from a registry image) as a Kubernetes Deployment + Service
  • An Envoy Backend is created pointing to the service's FQDN (ClusterIP:port)
  • An MCPRoute exposes the MCP server at /enterpriseai/gateway/mcp/<name> on the Gateway
  • The MCPRoute references the Gateway (nai-ingress-gateway) as parentRef
  • NAI labels resources with nai.nutanix.com/feature: mcp and nai.nutanix.com/mcp-server-type: local
  • The container image, port, and resource limits are configurable in the NAI UI
