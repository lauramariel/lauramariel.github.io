MCP Server (Remote) Creation Flow

What gets created on Kubernetes when you create a "Remote MCP Server" in NAI (e.g., "weather" pointing to nws.caseyjhand.com)

Key Takeaways

  • A Remote MCP Server does NOT create any pods — it only creates Envoy Backend + MCPRoute
  • The Backend points to an external FQDN (e.g., nws.caseyjhand.com:443)
  • Envoy proxies MCP requests directly to the remote server over TLS
  • The MCPRoute filters which tools are exposed via toolSelector.include
  • No in-cluster resources beyond the Envoy CRDs — lightweight and stateless
  • Labels: nai.nutanix.com/mcp-server-type: remote
